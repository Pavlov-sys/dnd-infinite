# Roadmap

Priorities follow the feature set of a full online character platform, with the character builder first.

## v0.1 — Foundation (done)
- [x] Rules engine, dice roller, local storage, JSON import/export
- [x] Builder: class, background, species, abilities, spells, equipment, details (levels 1–20)
- [x] Interactive sheet with rolling, HP, slots, resources, rests, conditions, inventory
- [x] Compendium browser and homebrew content packs

## v0.2 — Complete the SRD data (done)
- [x] Builder flow: settings, list → preview → confirm, feature sections with choice badges
- [x] Full SRD 5.2 spell list, equipment, magic items and monsters (generated by tools/import-srd.py)
- [x] Full rules text for class features, subclass features, species traits and feats
- [x] Class tables verified against the SRD data (fixed Fighter, Rogue and Wizard skill lists)
- [x] Homebrew editor (forms for every content type, JSON for classes)
- [ ] Eldritch Invocations, Metamagic options and Wild Shape forms as builder choices
- [ ] Subclass/feature options (Hunter's Prey, Blessed Strikes, Land type…) as builder choices
- [ ] Bard Lore and Barbarian Primal Knowledge extra skills; Wizard Scholar Expertise; Paladin/Ranger cantrip fighting-style options

## v0.4 — More content (done)
- [x] Optional openly licensed packs: Tome of Heroes, Black Flag classes, Tal'Dorei, Open5e Originals, Deep Magic spells, Vault of Magic, Tome of Beasts, Spells That Don't Suck
- [ ] Black Flag spell lists and Talents; Mechanist augments and Vanguard stratagems as builder choices
- [ ] Subclass-granted spell lists (circle/oath/domain spells) applied automatically

## v0.6 — Bring your characters (done)
- [x] Import D&D Beyond character sheet PDFs (no libraries; reads form fields, including compressed PDFs)
- [x] Import report: matched, approximate, missing content and number-by-number comparison with the original
- [x] "Other proficiencies, feats & spells" for things that don't come from a builder choice
- [x] Placeholders for unknown classes, subclasses, species, backgrounds, feats and spells, saved to My Homebrew and reused on later imports
- [ ] Import D&D Beyond's character JSON (more exact than the PDF: base scores, chosen bonuses, prepared spells)
- [ ] Import multiclassed characters once multiclassing exists

## v0.9 — Quick sheet adjustments (done)
- [x] ⚙ Adjust side panel inside the sheet, using the sheet's own theme
- [x] Bonus or exact value for AC, initiative, speed, max HP, passives, spell attack and DC, every save and skill; proficiency, half and expertise by hand
- [x] Advantage and disadvantage entries (all saves, one ability, one skill, initiative, attacks, death and concentration saves) shown as A/D badges and applied to rolls
- [x] Add spells from the whole compendium (cantrip, prepared, spellbook, or another source with an optional free Long Rest cast); remove spells
- [x] Add items from the catalogue with a quantity (weapons, armor, clothing, gear, tools, magic items), create custom items of any type, edit name/weight/notes

## v0.5 — Builder depth
- [ ] Multiclassing (prerequisites, combined spell slots)
- [ ] Rolled HP per level; manual overrides for any stat
- [ ] Spellbook management for Wizards; ritual casting; upcasting UI
- [ ] Magic items with attunement and modifiers
- [ ] Portrait upload, print/PDF sheet layout

## Homebrew editor (done in v0.3)
- [x] Form-based editors for every content type (classes via JSON)
- [ ] Pack validation with clear errors; pack versioning and dependencies
- [ ] Share packs by link/file

## v0.6 — Accounts, sync & campaigns
- [ ] Optional self-hostable sync server (characters & packs across devices)
- [ ] Campaigns: DM invites, party view, shared homebrew, DM notes
- [ ] Shared dice log for the party
- [ ] Integration with the session journal

## Later
- [ ] Encounter builder and monster stat blocks (SRD monsters)
- [ ] Offline PWA install, mobile layout polish
- [ ] Translations
